# 控制面持久化前置决策

本变更阶段不新增或修改 Gateway 配置库表、字段、索引、约束、DAO、PO、Mapper 或迁移脚本。

数据源、模板、策略和 Tool 绑定先使用测试 profile 的内存/配置 Registry，以验证执行契约和安全边界。正式控制面持久化前，需要由 Xerina 另行确认：

- 数据源、模板、策略和 Tool 绑定的业务含义与生命周期；
- 字段结构、版本发布状态、唯一性和兼容策略；
- 密钥引用方式及轮换/失效语义；
- 与现有 Gateway 配置库的迁移和回滚方案。

在上述确认完成前，MVP 只允许运行时配置注入目标数据源凭证，且不把凭证写入仓库。

方案 A 已选定；候选表结构、ER 图和方案比较见 [MySQL 控制面持久化方案与 ER 决策输入](persistence-options.md)。该记录仍不是 DDL，`9.1` 需要完成字段、生命周期和迁移子项确认后才能闭环。
