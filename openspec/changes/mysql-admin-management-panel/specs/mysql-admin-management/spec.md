## Purpose

为管理员提供一套安全、可审计、可供静态管理前端消费的 MySQL 数据源、SQL 模板和 Gateway Tool 绑定管理入口，使已打通的 MySQL SQL 执行链路具备完整的配置生命周期。

## ADDED Requirements

### Requirement: 管理员可以分页查询和查看 MySQL 数据源

系统 SHALL 提供 MySQL 数据源的分页查询、条件筛选和详情查看能力，列表结果 SHALL 返回名称、主机摘要、数据库名、只读状态、启用状态、关联模板数量、最近更新时间和连接健康状态；详情结果 SHALL 返回可编辑配置，但不得返回密码、密钥、密文、nonce 或完整敏感连接串。

#### Scenario: 按名称和状态分页查询数据源

- **WHEN** 管理员提交名称、启用状态、健康状态和分页参数
- **THEN** 系统返回符合条件的数据源分页结果、总数、当前页和页大小

#### Scenario: 查看数据源详情时隔离敏感字段

- **WHEN** 管理员打开一个已存在的数据源详情
- **THEN** 系统返回非敏感连接配置和脱敏后的主机摘要，并明确标识密码需要重新填写，不返回原密码或可逆密文

### Requirement: 管理员可以创建、编辑、删除和切换 MySQL 数据源状态

系统 SHALL 支持 MySQL 数据源的新建、编辑、删除和启停操作；新建数据源 SHALL 默认停用；更新密码 SHALL 采用“有值才覆盖、无值保持原值”的语义；删除被任一 MySQL 模板或绑定关系引用的数据源时，系统 SHALL 拒绝操作并返回稳定的引用冲突错误。

#### Scenario: 创建数据源默认停用

- **WHEN** 管理员提交合法的数据源名称、连接信息、只读策略和密码
- **THEN** 系统创建数据源并返回资源标识，启用状态为停用，响应不包含密码或密文

#### Scenario: 编辑数据源不覆盖原密码

- **WHEN** 管理员编辑数据源并省略密码字段
- **THEN** 系统只更新提交的非敏感字段，原密码保持有效且响应继续隐藏敏感字段

#### Scenario: 删除被引用的数据源

- **WHEN** 管理员删除仍被 MySQL 模板或绑定关系引用的数据源
- **THEN** 系统拒绝删除，返回稳定的 `DATASOURCE_IN_USE` 类错误，并返回可定位的引用数量或资源摘要

#### Scenario: 切换数据源启用状态

- **WHEN** 管理员对数据源执行启用或停用
- **THEN** 系统原子更新状态并返回最新状态，停用数据源不得被新的模板执行或绑定发布使用

### Requirement: 管理员可以管理 MySQL SQL 模板

系统 SHALL 以 `mcp_protocol_mysql` 记录作为 SQL 模板管理对象，支持分页、筛选、详情、新建、编辑、删除和启停；模板 SHALL 展示模板名称、协议标识、数据源、只读 SQL、参数契约、资源上限、状态、绑定 Tool 数量和更新时间。

#### Scenario: 查询 SQL 模板列表

- **WHEN** 管理员按模板名称、协议标识、数据源和状态查询
- **THEN** 系统返回分页模板列表，并为每条记录返回可读的 SQL 摘要、参数数量、绑定数量和状态

#### Scenario: 创建 SQL 模板执行安全校验

- **WHEN** 管理员提交 SQL、数据源、参数契约和行数/超时/结果大小限制
- **THEN** 系统校验 SQL 语法、只读策略、参数映射、数据源状态和资源上限，全部通过后创建默认停用的模板

#### Scenario: 拒绝不安全 SQL

- **WHEN** 提交的 SQL 包含写操作、危险语句、未声明参数或超出资源上限
- **THEN** 系统拒绝保存，返回字段级校验错误，不创建或修改模板

### Requirement: 启用后的 SQL 模板遵循不可原地覆盖规则

系统 SHALL 防止启用状态下的模板原地覆盖 SQL 正文、数据源或参数契约；管理员需要修改这些核心语义时，系统 SHALL 返回稳定的生命周期冲突错误，并引导创建新的协议记录或先停用原模板；普通描述、展示名称等非执行语义字段可按契约更新。

#### Scenario: 修改启用模板的 SQL

- **WHEN** 管理员尝试修改已启用模板的 SQL 正文
- **THEN** 系统拒绝修改并返回 `ENABLED_TEMPLATE_IMMUTABLE` 类错误，原模板保持可执行状态

#### Scenario: 停用后修改模板核心语义

- **WHEN** 管理员先停用模板，再提交新的 SQL、数据源或参数契约
- **THEN** 系统重新执行完整安全校验，校验通过后保存并保持停用状态

### Requirement: 管理员可以管理 Gateway Tool 与 MySQL 模板绑定

系统 SHALL 支持按 Gateway 查询绑定、创建、编辑、删除和启停绑定；绑定 SHALL 维护工具名称、描述、版本、协议类型、协议标识、关联 Gateway、MySQL 模板和数据源关系；新建绑定 SHALL 默认停用，工具名称在同一 Gateway 范围内 SHALL 保持唯一。

#### Scenario: 创建绑定校验关联关系

- **WHEN** 管理员提交 Gateway、工具名称、MySQL 模板和协议标识
- **THEN** 系统校验 Gateway、模板、数据源和协议类型关系均存在且状态允许绑定，成功后创建默认停用的绑定

#### Scenario: 拒绝重复工具名称

- **WHEN** 管理员在同一 Gateway 下创建已存在的工具名称
- **THEN** 系统拒绝保存并返回稳定的唯一性冲突错误，不影响已有绑定

#### Scenario: 切换绑定状态影响运行时发现

- **WHEN** 管理员启用或停用绑定
- **THEN** 系统返回最新状态；停用绑定不得出现在对应 Gateway 的 `tools/list`，也不得被 `tools/call` 调用

### Requirement: 管理 API 提供统一分页、错误和安全响应

系统 SHALL 为数据源、SQL 模板和绑定资源提供统一的 REST 管理契约，成功响应 SHALL 遵循项目统一的 `Response`/`ResponsePage` 结构，失败响应 SHALL 包含稳定错误码、可读消息和可定位字段；所有响应、异常和日志 SHALL 禁止输出密码、Token、Authorization、密钥、密文、nonce 和完整敏感 JDBC 信息。

#### Scenario: REST 分页响应

- **WHEN** 管理员请求任一资源的分页接口
- **THEN** 系统返回统一的列表数据、总数、页码、页大小和成功状态结构

#### Scenario: 领域校验错误映射

- **WHEN** 请求违反唯一性、引用完整性、状态生命周期或 SQL 安全规则
- **THEN** 系统返回对应稳定错误码和字段级提示，HTTP 响应不泄露内部堆栈或 SQL 敏感内容

### Requirement: 管理前端提供完整的资源工作台

管理员 UI SHALL 在现有静态管理站点中提供数据源、SQL 模板和 Tool 绑定入口，并复用统一的深空背景、左侧导航、顶部搜索、指标卡、注册表与右侧详情检查器布局；页面 SHALL 支持搜索分页、新建/编辑表单、关联资源选择、启停、删除确认、校验错误展示、引用冲突提示和敏感字段遮罩，UI 只能调用管理 REST，不得直接访问控制库。

#### Scenario: 从导航进入 MySQL 资源页面

- **WHEN** 管理员从左侧 MCP 资源导航进入数据源、SQL 模板或 Tool 绑定
- **THEN** 页面使用同一套产品视觉与布局，当前资源导航项高亮，并加载对应 REST 列表数据

#### Scenario: 新建模板表单展示关联资源

- **WHEN** 管理员打开新建 SQL 模板表单
- **THEN** 页面提供数据源选择、SQL 编辑、参数契约、执行护栏和绑定预览，并在提交前展示字段级校验结果

#### Scenario: 敏感字段遮罩和删除确认

- **WHEN** 管理员编辑数据源或删除有影响的资源
- **THEN** 密码字段默认遮罩且不回显原值，删除操作要求二次确认并在引用冲突时展示稳定错误和关联资源提示
